
# বাজার দর (BazarDor)

A Bangla-based grocery price tracking web application that helps users explore daily essential product prices, compare price changes, and view market-wise price information in one place.

## Technologies Used

- Next.js
- React
- Tailwind CSS
- Better Auth
- Lucide React
- React Fast Marquee
- date-fns
- REST API

## Key Features

1. **Product Categories** – Browse essential products by category.
2. **Price Tracking** – View today's prices and compare them with yesterday, last week, and last month.
3. **Price Comparison** – Track price increases, decreases, and percentage changes.
4. **Market-wise Prices** – Explore minimum and maximum product prices across different markets.
5. **User Authentication** – Sign up, sign in, manage profiles, and sign out.

## API

Base URL:
`https://api.api-store.workers.dev/api/bazardor`

## Getting Started


git clone <your-repository-url>
cd bangla-bazar
npm install
npm run dev


Open [http://localhost:3000](http://localhost:3000) to view the application.


**Note:** Product prices are estimates and may vary depending on market conditions, location, and time.
